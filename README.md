# Glyph Garden

*A Grammar of the Seasons*

> A geometric design language for constructing seasonal glyphs through a shared system of radial growth, symmetry, and visual hierarchy.

---

## Overview

Glyph Garden is an exploration of visual language.

Rather than designing a collection of seasonal icons independently, the project seeks to develop a coherent geometric grammar from which those icons naturally emerge. Each glyph is intended to be an expression of the same underlying system rather than an isolated illustration.

The first five glyphs represent:

- ❄ Winter
- 🌸 Spring
- ☀ Summer
- 🍂 Autumn
- 🧭 New Year

Together they form the first "vocabulary" of the Grammar of the Seasons.

---

## Philosophy

Glyph Garden begins with principles rather than artwork.

Instead of asking:

> "How should a snowflake look?"

the project asks:

> "What is the simplest geometric expression of crystallization?"

Every seasonal glyph is treated as an act of structured growth from a common center.

The goal is not to imitate nature, but to build a visual language that feels as though it could have been discovered within it.

## Design Process

The project develops through a series of increasingly specific artifacts.

```text
Constitution
        ↓
Design Brief
        ↓
Geometry Specification
        ↓
Construction Plates
        ↓
Module Sheets
        ↓
Assemblies
        ↓
Critique
        ↓
Design Decisions
        ↓
Pattern Library
```

Each stage introduces exactly one new idea.

Successful discoveries become part of the grammar.

---

## Construction Plates

Construction Plates establish the geometric foundation of the language.

Each plate introduces one concept and deliberately postpones everything else.

For example:

| Plate | Introduces |
|--------|------------|
| 000 | Construction Universe |
| 001 | Primary Stem |
| 002 | Growth Stations |
| 003 | Branch Vocabulary |
| 004 | Rotational Assembly |

Construction Plates are documentation as much as drawings.

---

## Design Principles

The project follows several guiding principles.

- Every line serves a structural purpose.
- Complexity emerges through repetition.
- Geometry should remain legible.
- Empty space is an active design element.
- Growth is expressed rather than illustrated.
- Every glyph belongs to the same visual family.

These principles are expanded in the Constitution.
